# 6. JavaScript Requirements

Create:

```text
sections/<SECTION_NAME>/<SECTION_NAME>.js
```

The JavaScript must follow this exact architecture:

```text
DOMContentLoaded
        ↓
Find section container
        ↓
Fetch section HTML
        ↓
Check response
        ↓
Convert response to text
        ↓
Insert HTML into container
        ↓
Call initialization function
        ↓
Find newly inserted elements
        ↓
Validate elements
        ↓
Add event listeners
        ↓
Handle section functionality
```

Use this structure:

```javascript
document.addEventListener("DOMContentLoaded", () => {
    const sectionContainer = document.getElementById("<SECTION_NAME>");

    if (!sectionContainer) {
        console.error(
            "<SECTION_NAME> container not found."
        );
        return;
    }

    fetch("sections/<SECTION_NAME>/<SECTION_NAME>.html")
        .then((response) => {
            if (!response.ok) {
                throw new Error(
                    "Failed to load <SECTION_NAME>.html"
                );
            }

            return response.text();
        })
        .then((data) => {
            sectionContainer.innerHTML = data;

            initialize<SectionName>();
        })
        .catch((error) => {
            console.error(
                "<SECTION_NAME> loading error:",
                error
            );
        });
});

function initialize<SectionName>() {
    // Find elements created by the HTML
    // Validate required elements
    // Add event listeners
    // Implement section-specific functionality
}
```

Adapt:

```text
<SECTION_NAME>
<SectionName>
```

to the actual section name.

For example:

```text
hero
Hero
```

becomes:

```javascript
initializeHero();
```

---

# 7. Critical JavaScript Rule

The initialization function MUST execute **only after** the HTML has been inserted.

Correct:

```javascript
.then((data) => {
    sectionContainer.innerHTML = data;

    initializeHero();
});
```

Incorrect:

```javascript
initializeHero();

fetch(...);
```

The reason is that the section's HTML elements do not exist in the DOM until `fetch()` finishes and:

```javascript
sectionContainer.innerHTML = data;
```

has executed.

---

# 8. JavaScript Responsibilities

Separate the JavaScript into two responsibilities.

## A. Loading responsibility

```text
DOMContentLoaded
→ Find container
→ Validate container
→ Fetch HTML
→ Check response
→ Convert to text
→ Insert HTML
→ Initialize section
```

## B. Functionality responsibility

```text
initialize<SectionName>()
→ Find section elements
→ Validate required elements
→ Add event listeners
→ Implement interactions
```

Each section must have its own initialization function.

Examples:

```javascript
initializeNavbar();
initializeHero();
initializeAbout();
initializeServices();
initializeFooter();
```

Do not create one large JavaScript function that controls multiple unrelated sections.
